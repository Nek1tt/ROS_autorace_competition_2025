# AutoRace ROS Competition 2025

Решение команды **ROSchupepiki** для соревнования AutoRace 2025 на базе ROS 2 Humble и Gazebo Harmonic. Робот проехал трассу на максимальный балл за 101.065 секунд и занял первое место.

## 📋 Описание проекта

Автономная система управления роботом для прохождения трассы AutoRace с выполнением шести миссий. Решение включает компьютерное зрение, PID-контроллер следования по линии, детекцию дорожных знаков и препятствий, а также специализированные алгоритмы для каждой миссии.

## 🎯 Реализованные миссии

### 1. Светофор
- **Задача:** Стартовать на зелёный сигнал светофора
- **Реализация:** Детекция зелёного цвета в HSV пространстве, робот начинает движение только после обнаружения зеленого света
- **Узел:** `monitor.py` - метод `is_green()`

### 2. Перекрёсток
- **Задача:** Проехать круговой перекрёсток согласно дорожному знаку (влево/вправо)
- **Реализация:** 
  - Распознавание синих дорожных знаков со стрелками
  - Анализ направления стрелки через распределение белых пикселей
- **Узел:** `monitor.py` - метод `process_arrow()`

### 3. Препятствия на строительной площадке
- **Задача:** Объехать оранжевые конусы, не выезжая за пределы трассы
- **Реализация:**
  - Детекция оранжевых конусов в HSV (0-20° и 160-180°)
  - Секвенциальная система маневров (движение → поворот → движение)
  - 8-шаговый алгоритм объезда: вперёд → вправо (65°) → вперёд → вправо (20°) → вперёд → влево (-80°) → вперёд → вправо (80°) → вперёд
  - Одометрия для точного контроля дистанций и углов
- **Узлы:** `konus_detection.py`, `lane_follower.py`

### 4. Безопасный обгон
- **Задача:** Объехать припаркованный автомобиль
- **Реализация:** Использование базового алгоритма следования по линии (миссия до конца не реализована)
- **Узел:** `lane_follower.py`

### 5. ArUco маркер
- **Задача:** Распознать ArUco маркер, вычислить √ID и отправить в топик `/mission_aruco`
- **Реализация:**
  - Детекция ArUco маркеров (DICT_6X6_250)
  - Кроп изображения для оптимизации (60% справа, 40% снизу)
  - Порог площади маркера для подтверждения близости
  - Однократная отправка результата
- **Узел:** `aruco_detection.py`
- **Топик:** `/mission_aruco` (Float32)

### 6. Туннель
- **Задача:** Проехать через тёмный туннель без визуальной навигации
- **Реализация:**
  - Детекция входа по соотношению тёмных пикселей (>60%)
  - Движение с постоянной скоростью и небольшим угловым смещением
  - Детекция выхода по яркости (>65% светлых пикселей)
- **Узел:** `tunnel_detection.py`

### Финишная линия
- **Детекция:** Анализ шахматного паттерна (чёрно-белая клетка)
- **Логика:** Проезд 0.8м после обнаружения финиша, затем полная остановка
- **Узел:** `is_finish.py`

## 🚀 Установка и запуск

### Требования

- Ubuntu 22.04
- ROS 2 Humble
- Gazebo Harmonic
- Python 3.10+

### Установка зависимостей
```bash
# Переходим в workspace
cd ~/ros2_ws/src

# Клонируем репозиторий
git clone https://github.com/Nek1tt/ROS_autorace_competition_2025.git

# Устанавливаем зависимости
cd ~/ros2_ws
rosdep install --from-paths src --ignore-src -r -i -y --rosdistro humble

# Собираем проект
colcon build --packages-select autorace_camera autorace_core_ROSchupepiki robot_bringup robot_description referee_console

# Применяем окружение
source install/setup.bash
```

### Запуск соревнования

Откройте **3 терминала** и выполните команды:

**Терминал 1 - Симуляция и робот:**
```bash
source ~/ros2_ws/install/setup.bash
ros2 launch robot_bringup autorace_2025.launch.py
```

**Терминал 2 - Управляющие узлы:**
```bash
source ~/ros2_ws/install/setup.bash
ros2 launch autorace_core_ROSchupepiki autorace_core.launch.py
```

**Терминал 3 - Судейская система:**
```bash
source ~/ros2_ws/install/setup.bash
ros2 run referee_console mission_autorace_2025_referee
```

## 🎮 Параметры настройки

### PID контроллер (в коде lane_follower.py)
```python
# Параметры объявляются в autorace_core_ROSchupepiki/lane_follower.py
Kp_ang: 0.008        # Пропорциональный коэффициент (угловая скорость)
Ki_ang: 0.0          # Интегральный коэффициент
Kd_ang: 0.002        # Дифференциальный коэффициент
start_speed: 0.3     # Линейная скорость (м/с)
start_offset: 0.0    # Смещение центра
```

### Детекция линий
В основном узле `lane_follower.py`:
- **Жёлтая линия (HSV):** H: 20-30, S: 100-255, V: 100-255
- **Белая линия (HSV):** H: 0-255, S: 0-255, V: 230-255

### Перспективная проекция
```yaml
top_x: 72       # Ширина трапеции сверху
top_y: 4        # Высота верхнего края
bottom_x: 115   # Ширина трапеции снизу
bottom_y: 120   # Высота нижнего края
```

## 📊 Топики ROS

### Подписки
- `/color/image` - RGB изображение с камеры
- `/color/image_projected` - Преобразованное изображение (bird's eye view)
- `/odom` - Одометрия робота

### Публикации
- `/cmd_vel` - Команды управления (Twist)
- `/is_green` - Статус зелёного света (Bool)
- `/is_cone` - Обнаружение конусов (Bool)
- `/is_tunnel` - Статус туннеля (Bool)
- `/is_sign` - Обнаружение знака (Bool)
- `/intersection_sign` - Направление на перекрёстке (String)
- `/mission_aruco` - Результат ArUco миссии (Float32)
- `/robot_finish` - Финиш соревнования (String)

## 📈 Архитектура решения

### State Machine (Конечный автомат)
Робот использует систему состояний для управления маневрами:

1. **IDLE** - Ожидание / следование по линии
2. **MOVING** - Движение вперёд на заданное расстояние
3. **TURNING** - Поворот на заданный угол

## 🐛 Известные ограничения

- Требуется хорошее освещение для детекции цветных объектов
- Скорость ограничена 0.3 м/с для стабильности
